បន្ថែមពីនេះសិស្សក៏បានបង្ហាញអំពីគោលការណ៍ដំណើរការរបស់ Matrix Keypad ដែលអនុញ្ញាតឱ្យអ្នកប្រើបញ្ចូលលេខកូដ (Password) តាមរយៈគ្រាប់ចុច។ ពួកគេក៏បានពន្យល់អំពីការតភ្ជាប់ជួរដេក និងជួរឈរ (Rows and Columns) របស់ Keypad និងរបៀប ដែលប្រព័ន្ធអាចអានការចុចគ្រាប់ចុចនីមួយៗ ដើម្បីទទួលបានទិន្នន័យបញ្ចូល។

English:


Project Presentation — Smart Lock System: How can a Matrix Keypad and Servo Motor work together to create a smart locking system?


As part of the Robotics Engineering course, students presented their Smart Lock System project, integrating a Matrix Keypad, Servo Motor, electronics, and programming to build a smart locking mechanism. They explained the key components, including the Arduino main board, matrix keypad, servo motor, and power supply, highlighting the role of each component in the system.


The students demonstrated how the Matrix Keypad allows users to enter a password using its buttons. They also explained the keypad's row-and-column wiring configuration and how the system reads individual key presses as input data.


In addition, the students introduced the Servo Motor, which provides precise control over rotational position. Through circuit wiring and coding, the servo motor can rotate to perform locking and unlocking actions according to the programmed conditions.
